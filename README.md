# Kibiya LMS starter project

A PHP/MySQL starter structure assembled from the code provided.

## Folder layout

```text
kibiya_lms_project/
├── config/
│   └── db.php
├── includes/
│   ├── header.php
│   └── footer.php
├── uploads/
│   └── .gitkeep
├── database.sql
├── management.php
├── admin_dashboard.php
├── facilitator_dashboard.php
├── student_dashboard.php
└── README.md
```

## Run locally on Windows with XAMPP

1. Install and start Apache and MySQL in the XAMPP Control Panel.
2. Copy this project folder into `C:\\xampp\\htdocs\\kibiya_lms_project`.
3. Open phpMyAdmin at `http://localhost/phpmyadmin`.
4. Choose **Import**, select `database.sql`, and run the import.
5. Check `config/db.php` and update the MySQL username/password if yours differ.
6. Open `http://localhost/kibiya_lms_project/management.php`.

## Important notes

- This is a starter bundle, not a complete working LMS. Pages linked in the navigation or dashboard (such as `index.php`, `login.php`, `register.php`, `courses.php`, `take_quiz.php`, `generate_certificate.php`, `logout.php`, `about.php`, `partners.php`, `gallery.php`, and `contact.php`) were referenced in the supplied code but were not included in the supplied text.
- The SQL intentionally does not insert the supplied admin password hash because it looks malformed and may not verify as `password123`. Create the admin with a fresh hash generated by PHP `password_hash()` before logging in.
- Before deployment, add CSRF protection to forms, authorization checks to every endpoint, HTTPS, robust upload handling, and secure production database credentials.
- Never use the default local `root` database account in production.
